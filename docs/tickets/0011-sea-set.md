## 目的
あたたかい 浅い 海と その そこ。すなはま・リーフ・しおふきじま、こんぶの もり、パステルの さんご、あわの いずみ。やさしい くじら。こわい もの（サメ・がいこつ・しずんだ 船・深海の 生き物）は 出さない。生き物は まるく、顔は 目だけ（口・歯・とげ なし）。
仮の 形と **同じ 名前・寸法・原点** で 作る。できたら `assets/models.json` の `_pending` から 外し、`node scripts/render-map.mjs 3-1` で 地図の 絵、`node scripts/render-zukan.mjs rainbow-shell sea-pearl iron-star mizutamari bubble-spring` で 図鑑の 絵を 描き直す。

## 共通仕様
- ファイル: `public/models/<名前>.glb`、生成スクリプトは `assets/blender/sea.py`（1 本に まとめる）
- 1 モデル 1 マテリアル（頂点カラー）。原点は 底面の 中心、前は +Z、モデル自身の 左は +X。アニメは なし（`kelp` の ゆれ、くじらの しっぽ、あわの 動きは ゲームが 描く）
- `awa-big`・`awa-pink` は すける ピンク（すけ 0.55）の 玉 ＋ 不透明な ぐるぐるの 帯（2 マテリアルで よい）
