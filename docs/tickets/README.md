| 状態 | 意味 |

## 進め方
1. ブランチ `codex/<番号>-<内容>` を切る（例: `codex/0001-proto-models`）
2. 受け入れ条件をすべて満たしてから PR を出す。PR タイトルは `[#0001] 内容`
3. PR 本文: チケット番号、変更点、確認方法、判断に迷った点、スモークのスクショ（または Blender プレビュー PNG）
4. 迷ったら PR に質問を書いて止まる。チケットにない機能は足さない
