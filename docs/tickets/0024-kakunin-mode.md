- 番号に ついて: コードには SHA-256 だけを 置く。**番号そのものは、コード・テスト・ドキュメント・コミットメッセージの どこにも 書かない**

## 目的
だいさんが iPad で、どの ステージも どの ミッションからも 遊んで 確かめられる ようにする。遊んだ 記録（クリア・図鑑・能力・ちず・つづきから）は 変えない。子どもが 住所の `?stage=` で テストステージや まだ 開いて ない ステージに 入れない ようにする。デバッグ機能では ない（本番に 出す。番号の うしろ）。

## 内容
1. 入口: 「おうちの かたへ」に 「かくにん モード」。4 けたの 番号を 大きな 数字ボタンで 入れる。SHA-256（`train-game-kakunin:<4 けた>`）で くらべる。合えば 端末に 印（専用の localStorage キー）。「かくにん モードを やめる」で 消す。まちがいは やさしく ゆれて 消える（ロックアウトなし）
2. ステージ一覧: 章ごとに 全ステージ（`world.json`）と 「てすとの コース」（0-0 〜 0-6）。ステージを 押すと ミッション名（ステージ JSON）と 「はじめから」。ミッションを 押すと `?stage=…&go=1&kakunin=1&mission=<n>`
3. 砂場の 走り: 能力は 保存 ＋ 前の ステージ ＋ オープニング ＋ 前の ミッションが 教える もの。保存には 何も 書かない（メモリの 写し）。クリアカードの あとは 一覧へ。小さな 「かくにん」の しるし（ボタンと かさならない。左きき でも）
4. `?stage=` の かぎ（本番ビルド、`navigator.webdriver` でない 端末、印なし）: テストステージ・まだ 開いて ない ステージ・`kakunin=`／`mission=` は タイトルへ もどす。ちずの `?stage=…&go=1` と「つづきから」は 通す

## 受け入れ条件
- まちがった 番号は ゆれて 消え、印は 残らない
- 印を 立てた 端末で、一覧に すべての 章と てすとの コースが ある。5-3 の 3 つめの ミッションから 始めると その ミッションの 能力が そろっている
- 走りの あと、進み具合の 保存が 1 バイトも 変わらない。しるしが 見え、ボタンと かさならない（左ききも）。クリアカードの あと 一覧に もどる
- `navigator.webdriver` を false に した 端末で、`?stage=0-0` と まだ 開いて ない `?stage=5-3` は タイトルへ もどり、開いている ステージは 開く
- Playwright スモークの スクショ（`tests/smoke/output/kakunin-list.png`・`kakunin-missions.png`・`kakunin-badge.png`）で 確かめられる こと
