## 目的
ステージ 1-1 の街・駅・登場人物。Phase 0 の仮モデルと同じ絵柄（ローポリ・フラット・単色）。子供向けなので角は丸め、色は明るく。

## 共通仕様
0001 の「共通仕様」と同じ（1 unit = 1 m、原点は底面中心、前方 +Z、Blender 上では前方 −Y、テクスチャなし、フラットシェーディング、1 ファイル 1 メッシュ、プレビュー PNG、スクリプト末尾で三角形数と bbox を出力）。
追加: 2 ポーズあるモデルは別ファイルにする（例 `cat-sleep` / `cat-stand`）。骨・アニメーションは使わない。
