# 0003 Blender発注: 1-1 はじまりの街 のモデル一式

- 状態: **発注中**（着手してよい）
- 担当: Codex
- 依存: なし（GO 後すぐ着手できる）
- 関連: `docs/PHASE1_DESIGN.md`、`docs/tickets/0001-blender-proto-models.md`（共通仕様はこれと同じ）

## 目的
ステージ 1-1 の街・駅・登場人物。`docs/WORLD_ART_DIRECTION.md` のC案相当の強めデフォルメと、形態写実度4 / 10を共通基準とする。色面は整理するが、構造・厚み・接合を省略した箱モデルにはしない。

## 共通仕様
0001 の座標・原点・1メッシュ・再生成可能性は継承する。造形と品質は `docs/WORLD_ART_DIRECTION.md` を優先し、制御ベベル、カスタム輪郭、必要な滑らかな接続を許可する。写真・外部テクスチャは使わない。プレビュー PNG とスクリプト末尾の三角形数・bbox出力は維持する。
追加: 2 ポーズあるモデルは別ファイルにする（例 `cat-sleep` / `cat-stand`）。骨・アニメーションは使わない。

### キャラクター品質の上書き（2026-09-14）

ユーザーレビューにより前提が変わったため、登場人物5点には
`docs/CHARACTER_3D_QUALITY_BAR.md` を優先する。旧来の一律フラット、
テクスチャなし、100KB以下、120〜320三角形という制限は登場人物には適用しない。
建物・駅・踏切・小物には `docs/WORLD_ART_DIRECTION.md` を適用する。
