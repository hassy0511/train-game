## 目的
ほんぶの わ から 3 つの もん（地図の ページの 色: 1 みどり・2 あお・3 むらさき）を くぐって、べつの せかいの 区画へ 行く。もんは 雲の アーチ と 雲の トンネル（白く 光る）。区画ごとの うしろむきの わき道の おくに 記録 3 こ。仮の形と **同じ 名前・寸法・原点** で 作る。できたら `assets/models.json` の `_pending` から 外す。

## 共通仕様
- ファイル: `public/models/<名前>.glb`、生成スクリプトは `assets/blender/world-set.py`
- 1 モデル 1 マテリアル（頂点カラー）。もんと トンネルと 記録は 少し 光る（夜の 区画でも 見える）
- 原点: 底面の 中心（記録は まん中）、前は +Z（もん・トンネルは 線路の 向き。線路が ±Z に とおる）
- アニメ なし
- **顔を つけない**（雲・小屋の まど・どんぐりを 目に 見せない）。字・数字・ロゴ なし（もんの 札は 絵 だけ。ページの 番号も 書かない）。実在の 門・鳥居・テーマパークの 入口に 似せない
