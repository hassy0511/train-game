## 目的
ステージ 2-2 の世界（ちいさく なって、草の 森の 中を 走る）。草は 見上げる 森、クローバーは 電車が のれる 台、花は 塔、みずたまりは 池。バッタと ちょうちょは なかま、くもは おわりに 見ていた ひと。
仮の形と**同じ名前・寸法・原点・部品の名前**で作る。できたら `assets/models.json` の `_pending` から外し、`node scripts/render-map.mjs 2-2` で地図の島の絵を描き直す。

## 共通仕様
- ファイル: `public/models/<名前>.glb`、生成スクリプトは `assets/blender/meadow.py`（1 本に まとめる）
- **1 モデル 1 マテリアル**（頂点カラー。パイプラインで 頂点カラーが 出せなければ、色を 焼き込んだ 1 枚の 画像でも よい）。草 約 500 本・花 約 80・クローバー 約 40 を 置くので、1 セル × 1 モデルで ドローコール 1 回に したい（`src/view/three/props.ts` は 同じ マテリアルの 部品を 1 つに まとめる）。例外は `water-strip`（半透明の 自分の マテリアル）
- 原点: 底面の中心、前は +Z、モデル自身の 左は +X（例外は 表に 書く）
- 虫は まるくて 抽象的に する。顔は 目だけ（口・きば・とげ・毛の とげとげ・服・帽子は つけない）。実在の 種類の もようは 使わない。こわく しない
- 草・花・クローバー・水は フラットシェーディング。虫の 体は スムーズシェーディング可
- 動かす 部品（バッタ・ちょうちょ）は 同じ GLB の 中の **名前つきの ノード**に する（`src/view/three/meadow.ts` が `getObjectByName` で さがして 回す）。ノードの 原点が 回る 軸（下の 表）。「1 ファイル 1 メッシュ」の 例外

### 動かす 部品（ノードの 名前・原点・回し方）
- `grasshopper`
  - `body`: 原点（胴・背中・前と 中の 小さな 足 4 本）
  - `head`: 首の 位置 [0, 0.95, 1.0]。rotation.x > 0 で 下を むく
  - `antenna-left`（+X）・`antenna-right`（−X）: `head` の 子。原点は 頭の 上の 付け根。X か Z で 回すと ゆれる
  - `leg-left`（+X）・`leg-right`（−X）: 大きな 後ろ足（太もも → 高い ひざ → すね → 足先）。原点は 腰 [±0.38, 0.74, −0.22]。rotation.x < 0 で 下・後ろへ ける
- `butterfly`
  - `body`: 体・頭・目・触角
  - `wing-left`（+X）・`wing-right`（−X）: 前ばね＋後ろばね（両面に 白い 丸）。原点は 体の 中心線の 上（x = 0）。rotation.z で はばたく（左は ＋で 上がる、右は −で 上がる）。回転 0 で 少し 上に 開いた 形
- `butterfly` は 原点が 体の 中心なので、`assets/models.json` に `"origin": "joint"` を 書く（`check-models` の 「いちばん 下が 床」の 確認を 外す）
