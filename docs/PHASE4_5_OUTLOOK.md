## 1. Phase 4: 1章仕上げ（「1章版」として公開できる形）

| 項目 | 案 | 備考 |
|---|---|---|
| 地図画面 | 俯瞰の絵地図。世界が「島」で浮かび、クリアした島の間に線路がつながっていく。未取得の調査記録は島の上に「？」。タップで出発 | DOM＋SVG で作れる（3D 不要）。絵は Blender でレンダした島の PNG を並べる案と、SVG のシンプルな図案の 2 案 |
| セーブ | `localStorage`（Capacitor では Preferences）。内容: クリア済みミッション、取得能力、調査記録、設定、スキーマ番号 | 端末ごと。クラウド同期はしない（個人情報を持たない方針） |
| タイトル画面 | Phase 1 で最小版あり。「つづきから」「せってい」を足す。ゲーム名は残課題 | |
| 設定 | 音量（BGM／効果音）、ゆれ演出のオンオフ（酔い対策）、左利き（レバーとボタンを左右入れ替え） | 子供向けなのでアイコン主体 |
| 音 | 効果音は合成で続けられる。**BGM 3 曲**は作り方を決める必要がある（§3） | 権利上、既存曲・発車メロディは不可 |
| PWA | ホーム画面に追加、オフライン動作（Service Worker でアセットを事前キャッシュ）。1章分のアセットは 5 MB 以内に | iPad Safari の PWA は音の解錠に注意 |
| 性能 | iPad Pro 2018 で 60 fps、最低端末で 30 fps。重い端末では描画解像度を 1.5 に落とす自動調整 | 計測は Phase 0 の仕組みを使う |
| 子供テスト | 実際の子供に説明なしで触ってもらう。見るのは「停車・ドア・汽笛まで一人で到達できるか」「どこで困るか」「飽きる時間」 | 2〜3 人、各 15 分 |
| 調査記録・図鑑 | 各ステージ 3 個。ライトで見つける（ライトは Phase 2）。図鑑は絵と 1 行の説明 | 「後の能力が必要な記録」は地図に「？」で出す |

順番の案: セーブ → 地図 → 設定 → 音 → PWA → 性能 → 子供テスト → 調整。

## 2. Phase 5 以降: 2章、ストア、課金

### 2章（ロケット解放）
- 2-1 おおきなきのくに／2-2 むしのはらっぱ／2-3 かざんの島。物語は STORY.md §6
- 新しい仕組み: ロケット（ゲージ、使用中ブレーキ不可、禁止区間）、しなる枝、小さくなる演出、落石、噴火カウントダウン
- 章 = 独立した線路網なので、1章と同じ作り方（設計 → GO → 基盤は Claude Code、見た目とモデルは Codex）

### ストア対応（Capacitor）
| 項目 | 内容 |
|---|---|
| iOS | Mac と Xcode が必要。Apple Developer Program（年額）。「キッズ」カテゴリに出すなら、第三者の広告・解析 SDK は使えない（この方針とは相性がよい） |
| Android | Google Play Console（初回のみ）。「ファミリー向け」ポリシーにも同様の制限 |
| 共通 | プライバシーポリシーの URL（外部通信なし・データ収集なしと書く）、年齢区分、ストア用スクショとアイコン（Blender 発注）、サポート連絡先 |
| 技術 | Capacitor でラップ。横持ち固定、セーフエリア、Android の戻るボタン、音の解錠。ネイティブ機能は Preferences（セーブ）だけ |

### 課金・広告
- 子供向け・権利安全を優先するなら **広告なし**。候補は「買い切り」か「1章無料＋章ごとの追加購入」
- ステージ解放は最初からデータ駆動（`unlock.purchase`）なので、どちらにも後から対応できる
- 実装は Capacitor の課金プラグインで。復元（機種変更）も必要

## 3. だいさんに決めてもらうこと（急がない）

1. **ゲーム名**（残課題。タイトル画面の文字は差し替えられる）
2. **BGM の作り方**: (a) 合成音でゲーム内生成（無料・素朴）、(b) 作曲を頼む（費用）、(c) 商用利用可のフリー素材（権利確認が必要）
3. **売り方**: 買い切り／1章無料＋追加購入／完全無料。広告は入れない前提でよいか
4. **出す順番**: iOS を先にするか、Android と同時か。Mac の手配方法
5. **地図の絵柄**: レンダした島の絵か、シンプルな図案か
6. **子供テストの相手**: 誰に、いつ頃

## 4. 今から仕込んでおくこと（Phase 1〜3 の間に）
- セーブのスキーマ番号を最初から持つ（Phase 4 で移行が楽）
- ステージ JSON の `unlock` を守り続ける（課金の後付け用）
- アセットの総容量を PR ごとに見る（5 MB 予算）
- 台詞はすべて JSON に置く（多言語化はしないが、差し替えを楽に）
