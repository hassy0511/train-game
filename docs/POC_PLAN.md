# 開発計画（POC〜1章完成）

最終更新: 2026-09-13

原則:
- 各Phaseの終わりに GitHub Pages で動くものがあり、だいさんが iPad で触れる状態にする
- 各Phaseは「設計提示 → だいさんのGO → 実装」の順で進める（CLAUDE.md参照）
- 先に基盤（Phase 0）を固め、ステージは 1-1 → 1-2 → 1-3 の順

---

## Phase 0: 基盤（遊べないが走れる）

目的: 全ステージ共通の土台を作り、技術リスクを潰す。

成果物:
- Vite + TypeScript + Three.js + Rapier の雛形。GitHub Pages に自動デプロイ
- スプライン線路の上を、運転席カメラで走れる（直線・カーブ・坂・ループなし）
- タッチUI: マスコンレバー、汽笛ボタン（音とクールダウン表示のみ）
- 分岐1箇所（矢印UIで選択）
- 仮の車両モデル（Blenderスクリプト生成の箱に近いもの）と仮の地面
- Rapier: 電車キネマティック登録、センサー1個（通過でログ）
- ステージJSONスキーマ v1 と、それを読むローダー（Phase 0用の仮ステージ1本）
- Playwrightスモーク: 起動→5秒走行→スクショ。CIで実行
- デバッグ: キーボード操作、スプライン可視化

決めること（この段階で確定）:
- 線路ゲージ・車両寸法・1unit=1m の基準
- 性能予算の初期値、動作保証最低端末
- ステージJSONスキーマ v1

確認: iPad Safari で 60fps 近く出るか。タッチ操作が親指で扱えるか。

## Phase 1: ステージ 1-1 はじまりの街

成果物:
- 3ミッション（はじめての運転／おきゃくをのせて／おとどけもの）
- 駅停車判定、ドアボタン、乗客の乗降演出
- 汽笛に反応する最初のアクター（踏切の猫）
- 相棒キャラ（運転席横）と吹き出し
- ミッション開始・達成・やり直しの流れ
- 終盤演出: あまのじゃくが線路を切る（仮モデルでよい）
- Blender発注: 街の建物セット（5〜8種）、駅、踏切、猫、相棒、あまのじゃく（仮）

確認: 子供が説明なしで停車・ドア・汽笛まで到達できるか。

## Phase 2: ステージ 1-2 きょうりゅうの谷 ＋ ジャンプ

成果物:
- ジャンプ（速度依存の飛距離、着地判定、クールダウン、落下→コミカル復帰）
- 能力解放の仕組み（解放演出、ボタン出現、セーブ）
- 逆標識ギミック、ライト実装（痕跡が光る）
- 恐竜アクター（寝る／汽笛で起きる／大型は起きない）、翼竜の群れ
- 落とし穴（線路の `gap`）
- 調査記録3個と図鑑UIの最小版
- Blender発注: 恐竜3種、シダ・岩セット、標識

確認: ジャンプの手触り。飛距離判断が子供に分かるか。

## Phase 3: ステージ 1-3 くものうえ

成果物:
- 重力逆転区間（`up`反転）
- 消えるジャンプ台（汽笛で再出現）
- 上昇気流（自動加速帯）
- 雲落下→ぽよん復帰
- 視界ゼロ区間とライト
- Blender発注: 浮島セット、雲、風見鶏、鳥

確認: 重力逆転で酔わないか。1章通しで遊んで飽きないか。
