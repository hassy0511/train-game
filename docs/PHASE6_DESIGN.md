### 2. 舞台とお話
- 虫の 目線の はらっぱ。草は 高さ 30〜45 m の 森で、クローバーの 葉は 電車が のれる 台に なる。花は 見上げる 塔、みずたまりは 池、小川は 大きな 川に 見える。後半の 線路は、草の くきから くきへ はった **くもの いと**

- 出（STORY §6）: 大きな くもの すが ワールドレールで はってある。くも「かぜで すが やぶれて、こまってたの」「ぐるぐる ぼうしの こが、なおして くれたの」。サカサは 線路で すを はり、そのかわりに いとで 線路を はった（**ぎゃくに はりかえた**）。2-1 の「たすけようと した…のかな？」が「やさしいのかも」へ 一歩 すすむ。遠くに けむりの 出ている 島が 見え、2-3 へ つなぐ

### 4. 新しいしくみ（ステージ JSON、スキーマ v1.6。`schemaVersion` は 1 の まま、追加は すべて 省略可）

#### 4.1 バッタ（`actors[]` の `grasshopper`）
- `onRail` の 横の 草の 葉に すわっている（`lateral`・`heightFromRail` で 葉の 上）
- のる:
  - `reactsTo: "none"`: 先頭が 葉の `hop` m 手前（既定 25）に 来ると、自分から 屋根に のる（0.6 秒の 放物線）
  - `reactsTo: "whistle"`: 先頭が `whistleRange` m 手前（既定 60）から 葉を `passBy` m（既定 8）過ぎるまで 汽笛ボタンが 光る。汽笛を 鳴らすと のる。`whistleRange` ＋ 30 m 手前で `hopperNear` を 言う
  - 空中では のらない。同時に のれるのは 1 ぴきだけ
- のっている あいだ:
  - ジャンプの 飛距離 = 速さ × 1.6 秒 × `power`（既定 2）、高さは `height` m（既定 8）。ふわっと とどく 25% の きまりと「今 とべば こえられる とき 光る」は ふつうの ジャンプと 同じ（2 倍で 計算する）
  - ジャンプボタンに `data-hopper="1"`: 輪が みどりに なり、バッタの 絵に かわる
  - 見た目: 胴は 先頭車の 屋根、頭は 窓の 上の はしから 下へ のぞく（車の 原点から [0.3, 3.15, 6.2]。運転席の 画面の 上 1/5 に 大きな 目と 触角が 見える）。ジャンプの とき 後ろ足で けって、「びよーん」の 音
  - 次の 切れ目まで 60 m に なると `hopperReady` を 言う（`{speed}` は `gapHint` の 段）
- おりる: 切れ目を こえて 着地したら、横の 葉へ ぴょんと おりて 触角を ふる（`hopperDone`）。切れ目の ない 所で ジャンプしても おりない（むだに ならない）
- バッタの 切れ目 = 葉より 先に ある 同じ 線路の 最初の 切れ目。のせないまま そこに 落ちたら `hopperFell` を 言い、その 切れ目の `rewind` へ もどる（バッタは 葉に もどる）
- 巻き戻し: のっている バッタと、葉が 戻り先より 先に ある バッタは、葉に もどる
- params（既定、`src/train/params.ts` の `GRASSHOPPER`）: `{ hop: 25, whistleRange: 60, passBy: 8, power: 2, height: 8, gapHint: null }`
- 検証: 葉より 先 250 m 以内に 切れ目が あること。その 切れ目の `rewind` が 葉の `max(hop, whistleRange)` m 手前より 前に あること。同じ 線路の バッタは 150 m 以上 はなす

```json
{ "id": "batta-2", "type": "grasshopper", "reactsTo": "whistle",
  "onRail": { "railId": "main", "at": 760, "lateral": 5, "heightFromRail": 3 },
  "params": { "whistleRange": 60, "power": 2, "height": 8, "gapHint": "fast" } }
```

#### 4.2 ちょうちょと 花の 橋（`gimmicks[]` の `flower-bridge`。ちょうちょは この しかけの 中に いる）
- `railId` の `from`〜`to` は 小川（または きれた いと）の 切れ目。ローダーが この 線路の `gaps` に 足す（`rails[].gaps` には 書かない）。そのとき `rewind: { railId, at: rewindAt }`、`pit: false`、`bridge: 番号` を つける。幅は 44 m 以上に する（びゅーんでも とどかない 幅）
- ちょうちょは `butterflyAt` の 横 `butterflyLateral` m、高さ `butterflyHeight` m の 小さな 花で まっている
- 状態は 5 つ:
  - **まつ**（花の 上）: ライトが 消えていて、先頭が `butterflyAt − range − 20` 〜 `from` の あいだに いる とき、ライトボタンが 光り、`butterflyNear` を 言う
  - **ついてくる**: ライトが ついていて、先頭が `butterflyAt − range` より 先（花を 通りすぎた あとでも 追いつく）なら 飛び立つ。ちょうちょの 位置 sB は `先頭 + leadEff` を 目指して 動く（最大 `catchSpeed` 20 m/s）。高さは レールの 上 `butterflyHeight` m、左右に ±0.8 m ゆらゆら。`butterflyFollow` を 言う
    - 電車が `maxSpeed`（既定 8 m/s）より 速いと、leadEff が「速さ − 8」m/s で へり、窓の ほうへ おされる（`minLead` 4 m まで）。はばたきが 速く なり、`butterflyFast` を 1 回 言う。**失敗には しない**。遅く なれば 2 m/s で `lead` に もどる
  - **まつ（とちゅう）**: ついてくる とちゅうで ライトを 消すと、その場で ふわふわ まつ。ライトボタンが 光り、`butterflyWait` を 言う。ライトを つけると、また ついてくる
  - **とまる**: sB が つぼみ（`from − bud`）に 着くと つぼみに とまる。その場で `Rail.removeGap(from, to)` を よび（判定は すぐ つながる）、見た目は `bloomSeconds`（1.5 秒）で 花が ひらき、花びらが 手前から のびる。`bridgeOpen` を 言う
  - **ひらいた**: ステージの あいだ ずっと ひらいたまま（巻き戻しても 閉じない）。ちょうちょは 花に とまったまま
- 閉じた 橋に 近づく（`from` の 60 m 手前、ちょうちょが ついてきていない）と `budClosed` を 言う。落ちたら 失敗の 理由 `bridge` で `bridgeFell` を 言い、`rewindAt` へ もどる
- 巻き戻し（どの 失敗でも）: 橋が まだ 閉じていれば、`戻った 先頭 + lead ≤ butterflyAt` なら 花に もどる。そうでなければ `戻った 先頭 + lead` で まつ（いつも 電車の 前に いる）
- params（既定、`FLOWER_BRIDGE`）: `{ butterflyAt: 必須, butterflyLateral: -5, butterflyHeight: 4, range: 40, lead: 12, minLead: 4, maxSpeed: 8, catchSpeed: 20, bud: 12, budLateral: 4, size: 1, bloomSeconds: 1.5, rewindAt: butterflyAt − 60 }`
- 検証: `butterflyAt < from − bud − lead`、`to − from ≥ 44`、ほかの 切れ目と 重ならない、`rewindAt < butterflyAt − lead`、`butterflyAt`〜`from` の あいだに 分かれ道が ない（ちょうちょが 分かれ道を 通らない）

```json
{ "type": "flower-bridge", "railId": "main", "from": 1360, "to": 1408,
  "params": { "butterflyAt": 1250, "butterflyLateral": -5, "butterflyHeight": 4,
              "range": 40, "lead": 12, "maxSpeed": 8, "bud": 12, "budLateral": -4,
              "size": 1, "rewindAt": 1190 } }
```

#### 4.3 いとの はし（`gimmicks[]` の `fragile`）
- 先頭が `from − warn`（既定 80）に 来たら `fragileNear` を 言い、レバーの 目盛りを 光らせる（`maxSpeed` 以下で いちばん 速い 段 ＝ ゆっくり）。`to` を 過ぎるまで 光ったまま
- はしの 上（先頭が `from`〜`to`、空中でない）で 速さが `maxSpeed` ＋ 0.3（既定 7.5 ＋ 0.3）を こえると、いとが たわんで ぷるぷる ゆれ、`fragileShake` を 言う。こえたまま `grace` 秒（既定 1.0）たつと「ぼよよーん」に なる。遅く なれば 数えなおし（1 秒で 0 に もどる）
- ぼよよーん（失敗の 理由 `fragile`）: 電車を 止め（`emergencyStop`）、画面を 少し 沈める（ゆれは なし）、ぼよーんの 音（今の `playBoing`）、いとが 1 秒 びよんびよん。`fragileBoing` → `fragileBoingAfter` を 言い、葉っぱ色で ふわっと `rewindAt` へ もどる
- `to` を 過ぎたら `fragileClear` を 言い、目盛りの 光を 消す。空中では 判定しない
- 通れる 速さ（`maxSpeed` 7.5）: ゆっくり 5・ライトの ゆっくり 3.5・ライトの ふつう 7 は OK。ふつう 10・ライトの はやい 10.5 は だめ。**ライトが ついていても 困らない**
- たるみは 線路の 点 そのもので つける（ステージ JSON の 点で まんなかを 下げる）。見た目は、この 区間を 普通の 線路から ぬいて（2-1 の 枝と 同じ やり方）、白い いと 2 本と 細い 横糸、両はしの 草へ のびる 支えの いとで 描く
- params（既定、`FRAGILE`）: `{ maxSpeed: 7.5, grace: 1.0, warn: 80, rewindAt: from − 60 }`
- 使い回せる 先: 4-2 の 積み木の 橋（くずれやすい → ゆっくり）など。3-2 の 割れる 氷は ロケットで はやく わたる きまりなので、使わない

```json
{ "type": "fragile", "railId": "silk", "from": 170, "to": 220,
  "params": { "maxSpeed": 7.5, "grace": 1, "warn": 80, "rewindAt": 110 } }
```

### 3. 舞台とお話
- 青い海に浮かぶ、まるい火山の島。火山はときどき「ぽふっ」と白いけむりの わっかをはく。溶岩・赤い光・人や生き物に当たる石は出さない。石は軽い「かるいし」で、当たっても「ぽこん」。海に落ちると ぷかぷか浮く

### 5. 新しいしくみ（ステージ JSON、スキーマ v1.6）
新しいしくみは 3 つ。どれも区間（`gimmicks[]`）かステップの欄に書く。ステージによって変わる値はステージ JSON に、全ステージ共通の値は `src/train/params.ts` に置く。

#### 5.1 ロケット（能力 `rocket`、区間 `rocket`）
- 覚え方: `"unlocks": ["rocket"]` と、寸劇の `{ "unlock": "rocket" }`（1-2 のジャンプと同じ）。ボタンが出て、カメラのボタンが右上へ「ぴょーん」と飛んでいく（0.6 秒）。札は「ロケットを おぼえた！」。ロケットを持っているステージでは、最初からカメラは右上にある
- 押すと: つぶを 1 こ使い、`burn` 3 秒のあいだ `accel` 10 m/s² で `speed` 30 m/s まで加速する。レバーの段・ライトの減速・のぼり坂の引っぱりに関係なく加速し、止まっていても使える
- 使っている間: レバーは動かない（`setNotch` が false を返し、つまみが戻る。空中と同じ）。1 回の点火につき 1 回だけ、ピコ「ロケット ちゅうは レバーが きかないよ」。ブレーキ・きゅうブレーキは効かないが、ゲームの急停止（石・生き物）は効き、そこでロケットも終わる
- 終わったら: レバーの速さより速ければ、`settle` 5 m/s²（その段のブレーキのほうが強ければそちら）でレバーの速さへ戻る
- 押しても出ないとき: ボタンを うすくして、印を出す（`data-why`）。押すとピコが一言いう。つぶは減らない
  - 空中／点火中 → 何も言わない（連打しても 3 つぶを一気に使わない）
  - つぶ 0 →「からっぽ！ えきで まんたんに なるよ」
  - おやすみ区間（`allow: false`）→ 区間の `line`
  - つるつるざかの上 →「つるつる〜！ レバーが きかない！」
  - いま向かっている駅の停止線の `stationQuiet` 200 m 手前から／車止めの 150 m 手前から →「えきの ちかくは ロケット おやすみ」
- 使っている途中で上の区間に入ると、「ぷしゅっ」と終わる（失敗にはしない）
- つぶの回復: 駅から走り出すとき（`drive()` の始まり）と、失敗して戻ったときに満タン
- 光る（`data-glow`）: 点火中でなく、つぶがあり、押せる場所で、次のどちらか
  - (a) いまの線路で次の のぼり坂の `glowAhead` 40 m 手前から坂の上までで、v²÷(2×|pull|) ＜ 坂の残り＋2 m（いまのままでは のぼりきれない）
  - (b) `glow: true` の `rocket` 区間の中
- 光ったときの一言: ミッションで最初に光ったとき `rocketReady`。同じ坂で 2 回目に光ったとき `rocketAgain`。ミッションで最初に点火したとき `rocketGo`
- 飛距離の頭打ち: ジャンプ・ジャンプ台・しなる枝の飛距離は、速さを `JUMP.maxSpeed` 22 m/s で頭打ちにして計算する（ロケットのまま 1-3 や 2-1 を遊び直しても飛びすぎない。案 1 が見つけた問題）

#### 5.2 さか（区間 `slope`）
区間は `railId` の `from`〜`to`。電車の先頭で判定する。
- **のぼり（`pull` がマイナス）＝ きゅうな さか**: レバーでは加速せず、毎秒 |pull| m/s ずつ遅くなる。レバーが速さより下なら、その段のブレーキも足す。ロケット中は坂の引っぱりを無視する。速さが 0 になったら「ずるずる〜」: Train が `slip` 状態になり、1.2 秒で 6 m うしろへ下がる（s を実際に減らす。速さは 0 のまま、車輪から砂けむり）。同時に `slipped` イベント → 失敗の理由 `slip` → 白く包んで `rewind`（既定は `from − 60`）へ戻し、つぶを満タンにする。つぶが 0 だったら `slipEmpty` を言う
- **くだり（`pull` がプラス）＝ つるつるざか**: 毎秒 pull m/s ずつ速くなり、`max` で止まる。max より速く入ったら、3 m/s² で max まで落ちる。レバーは動かない（つまみに きらきらの印。1 回だけ `noBrakeLever`）。区間に入ったとき `noBrake` を 1 回言う。ロケットは使えず、点火中なら入口で終わる。区間を出ると、レバーの位置どおりに戻る
- ゲームの急停止（石にぶつかった）は、どちらの坂でも最優先で効く
- 先に言う: のぼり坂の 60 m 手前で、その坂の `line`（なければミッションの `steepNear`）を 1 回言う
- 見た目: のぼりは、赤茶の道床に黄色い「＞＞」（8 m おき）と、ふもとの札 `sign-steep`。くだりは、白っぽい灰色の道床と、上の札 `sign-slide`。道床の色は `rail-mesh` の頂点色を区間で変える（描画の回数は増えない）
- 速さの札: のぼり坂では いつもどおり。くだり坂は「つるつる〜」

```json
{ "type": "slope", "railId": "main", "from": 260, "to": 330, "params": { "pull": -6 } }
{ "type": "slope", "railId": "main", "from": 360, "to": 440, "params": { "pull": 3, "max": 20 } }
{ "type": "slope", "railId": "main", "from": 470, "to": 620,
  "params": { "pull": -6, "rewind": { "railId": "main", "at": 340 }, "line": "ながい さかだ！ ロケット 2かい！" } }
```
params の既定値: `pull`（必須）、`max: 20`（くだり）、`rewind: { railId: 同じ線路, at: from − 60 }`（のぼり）、`line: null`、`sign: true`。
共通の値: `SLOPE = { slipBack: 6, slipSeconds: 1.2, overMax: 3, nearDistance: 60, rewindBefore: 60 }`

#### 5.3 カウントダウン（ステップの `countdown`）
- ステップに `countdown` を書くと、そのステップの運転が始まるときに数え始める。前の駅のドアが閉まって、`timerStart` を言い終えたあと
- 減るのは `phase === "driving"` のときだけ（ゲームの時間で数える）。一時停止・失敗の演出・ドア・寸劇の間は止まる。止まっていても運転中なら減る
- パネル: 画面の上、速さの札の左どなり（停止ゲージとも、右上のカメラ・一時停止とも重ならない）。火山の絵、へっていくオレンジの帯、大きな数字（残り秒）を出す。残り 10 秒で絵が むずむず動き、`timeLow` を 1 回言う。赤くしない、点滅させない、ピッピッと鳴らさない
- セーフ: 先頭が `until` を通ったら（`until` がなければ、ゴール駅の停止ゾーン＝停止線の 30 m 手前に入ったら）止まる。パネルは緑の「セーフ！」になって 1.5 秒で消え、`timeSafe` を言い、曲も元に戻る
- 時間切れ: 失敗の理由 `timeUp`。火山が「はっくしょーん！」（大きな けむりの わっか、白いゆげ）→ 白く包む → `timeUp`（複数行）→ そのステップを始めた駅の停止線へ戻る（乗っている人はそのまま、つぶは満タン）。次の持ち時間は `seconds + min(assist × 時間切れの回数, assistMax)`
- ほかの失敗（石・ずるずる・駅の はやすぎ など）: 5 m 走るごとに「どこで、残り何秒だったか」を覚えておく。戻った場所を最後に通ったときの残り秒 ＋3 秒にする（持ち時間は こえない）。覚えがなければ満タン。ぽこん → すぐ時間切れ、にはならない
- 曲: `music` があれば、数えている間はその曲にする
- v1 からある `MissionDef.timeLimit` は使わない（迎えに行ったあとから数えたいので、ステップ単位にする）
- 寸劇に 2 つ足す: `{ "fx": "sneeze" }`（火山のくしゃみ。2.5 秒）と、`cutRail` の `style: "fall"`（線路と、`props` で指定した札の付いた橋げたが下の海へ落ちる。いまの上へ飛んでいく動きは、サカサが切るとき用に残す）

```json
{ "stationId": "misaki", "alight": 1,
  "countdown": { "seconds": 70, "until": { "railId": "kudari", "at": 885 },
                 "assist": 10, "assistMax": 30, "icon": "volcano", "music": "hurry" },
  "say": "ありがとう！ たすかったよ〜", "reply": "まにあったね！" }
{ "fx": "sneeze" }
{ "cutRail": { "railId": "kudari", "from": 765, "to": 865, "style": "fall", "props": "old-bridge" } }
```
共通の値: `COUNTDOWN = { lowAt: 10, sampleEvery: 5, restoreBonus: 3, safeShow: 1.5 }`

#### 5.4 つかいまわし（新しいしくみに数えない小さな手直し）
- **ころがる いし `rock-roll`**: 1-2 の `SmallDino` と同じ判定で、見た目だけ変える。空中でもこえられない。`warn` m で山の上の石が ぐらぐら（`rockNear`、なければ `params.say`）→ `startDistance` m で ころがり出し、`crossSeconds` かけて左（山）から右（海）へよこぎる → 海へ ぽちゃん、ぷかぷか浮く。よこぎっている間に先頭が `dangerDistance` まで来たら「ぽこん」（失敗の理由 `rock`）。既定は `{ startDistance: 60, crossSeconds: 4.5, dangerDistance: 6, lateral: 9, warn: 90 }`。平均 12 m/s 以下（ふつう）なら通ったあとに着き、はやい以上だと ぽこん
- **おちて とまる いし `rock-drop`**: 2-1 の `Squirrel` の「線路に落とす」だけを使う。汽笛は効かない。`warn` m で線路に かげ → `drop` m で ぽよんと落ちて止まる（`rockDrop`、なければ `params.say`）→ ジャンプでこえる（ジャンプボタンが光る。木の実と同じ判定）。既定は `{ drop: 35, warn: 60 }`。**電車より うしろの石は落とさない（d > 0 のときだけ）**。いまのリスは、戻ったあとに うしろで落ちて、すぐ ぶつかる おそれがある
- 石の共通 params: `rewind`（既定 `at − 80`）、`say`（その石だけの声かけ）、`hitAfter`（ぶつかったあとの一言。既定は ころがる石「ころころ いしは まってね」、おちる石「おちた いしは ジャンプで こえてね」）
- 猫の見た目を変える: `cat` に `params.look: "seabird"` を足す（うみどりが線路で ひなたぼっこ。起きたら ぱたぱた飛んでいく）
- 寸劇のカメラに `{ "camera": "fixed", "at": [x,y,z], "lookAt": [x,y,z] }` を足す（エンディングで、橋と火山と電車を 1 枚に入れるため）
- `props[].tag`（`cutRail` の `props` で落とすため）
- `rails[].base`: `{ "look": "rock", "depth": 3 }`（道床を 3 m 下へのばす）か、`{ "look": "rock", "toGround": true, "skip": [{ "from", "to" }] }`（地面までのばす。下ほど広い台形で「おね」に見える）。線路の下が浮いて見えないようにするためのもので、見た目だけ
- `fall: "cloud"`（白いゆげとして）、`fog`（わき道のゆげ）、`camera` 区間（さか①をうしろから）、分岐、乗客（調査員は `passenger` の配色ちがい。吹き出しの名前は今のまま「たんけんたいの なかま」）、`flock`（火山のまわりを回る うみどり。見た目だけ）

#### 5.5 せりふのキー（v1.6 で足す。既定の言葉を持たせる）
`steepNear` `rocketReady` `rocketGo` `rocketAgain` `rocketLever`（既定「ロケット ちゅうは レバーが きかないよ」）`rocketEmpty`（「からっぽ！ えきで まんたんに なるよ」）`rocketQuiet`（「えきの ちかくは ロケット おやすみ」）`slip`（「ずるずる〜… のぼれなかった」）`slipEmpty`（「ずるずる〜… ロケットが たりない！」）`slipAfter`（「ひかったら ロケットを おしてね」）`noBrake` `noBrakeLever`（「つるつる〜！ レバーが きかない！」）`rockNear` `rockDrop` `rockHit`（「ぽこん！ いしに ぶつかった〜」）`timerStart` `timeLow` `timeSafe`（「セーフ！」）`timeUp`（「はっくしょーん！」）。区間や石ごとの声は `params.line` と `params.say` に書く。

#### 5.6 読み込み時の検査（validate.ts に足す）
- `slope`: `pull` が 0 でない。`from` が線路の始まりから 30 m 以上あと、`to` が終わりから 10 m 以上手前。区間の中に、停止線・分岐・合流・切れ目がない。のぼり坂の `to` から、同じ線路で次に止まる駅の停止線まで 200 m 以上（`ROCKET.stationQuiet`）
- `rewind`（坂・石・切れ目）の戻り先が、どの `slope` の中にもない。ころがる石の `startDistance` の中にもない
- `rocket`: `railId`・`from`・`to` がある。`allow: false` と `glow: true` は同時に書かない
- `countdown`: `seconds > 0`。`until` がある線路が存在する。`assistMax ≥ 0`

### 付録 B: 曲（2-3）

曲は 2 つ。どちらも src/audio/songs.ts に、音符のデータとして書くオリジナル曲（既存の曲・発車メロディには似せない）。

1) volcano「かざんの しま」（2-3 のステージの曲）
- 雰囲気: 明るい南の島の冒険。こわい短調は使わない。火山は「元気な大きい山」
- テンポと拍子: 120 bpm の 4 拍子、stepsPerBeat 2（8 分音符）。はずむ（2 拍目と 4 拍目に軽いアクセント）
- 調: ヘ長調（F）。コード進行は F–Bb–C–F の明るい循環に、ときどき Dm
- 楽器（今の Voice の中で）:
  - bell ＋ wood（主旋律。鐘と木琴を重ねて、スチールドラムふうの きらきらした音）
  - bass（チューバふうの「ぼっ ぼっ」。1・3 拍にルート、ときどきオクターブで はねる）
  - pad（うすい和音。サビだけ）
  - drums（k–h–s–h の軽いリズム。2 小節ごとに「ぽこ」とタム風のアクセント）
- 形: 16 小節のループ（A 8 小節で、のぼっていくメロディ ＋ B 8 小節で「ぽふっ」と休符を入れる遊び）

2) hurry「いそげ！」（M3 のカウントダウン中だけ。3-3 の雪崩レースでも使う）
- 雰囲気: わくわくして急ぐ。あせらせすぎない。サイレン・警報に似せない
- テンポと拍子: 150 bpm の 4 拍子、stepsPerBeat 2

- 楽器: wood（16 分に近い速いきざみを 8 分で連打）、bass（8 分で刻む）、drums（k–h–s–h を休みなく）、bell（2 小節に 1 回の「ちゃらん」）
- 形: 8 小節のループ。ピッピッという電子音は入れない
