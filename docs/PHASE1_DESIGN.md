## 1. ステージの形

線路は 1 本の **周回（ぐるっと一周、約 720 m）**。逆走はまだ無いので、行って戻る形にはしない。

```
        さくらえき(180)                    みなとえき(360)
   ┌────────■────────────────────────────■────────┐
   │                                                  │
   │   ← 街の建物・木                                 │
   │                                                  │
 ■ たんけんたい ほんぶ(0)                     おかのえき(540) ■
   │                                                  │
   └──────────────╳───────────────────────────────────┘
              ふみきり(640) ねこ
```

| 場所 | 距離 | 役割 |
|---|---|---|
| たんけんたい ほんぶ | 0 m | スタート。M3 の届け先。エンディングの場所 |
| さくらえき | 180 m | M1 のゴール。M2 の最初の駅 |
| みなとえき | 360 m | M2 の 2 番目 |
| おかのえき | 540 m | M2 のゴール。M3 で荷物を積む |
| ふみきり | 640 m | 猫が寝ている（M3） |

各ミッションは前のミッションが終わった駅からそのまま続く（電車は止まったまま）。

## 3. 新しい仕組み（基盤側）

### 駅停車（提案 = 「ゆっくり」なら自動で止まる）
- 駅の手前 30 m からが「駅ゾーン」。ゾーンに **「ゆっくり」以下で入ると自動でブレーキがかかり、停止位置にぴたっと止まる**
- 「ふつう」以上で入ると通り過ぎる → 相棒「はやすぎた〜！」→ 失敗扱い（§下）
- 理由: 子供が位置合わせで詰まらない。速度を落とす判断だけを覚えさせる。M1 はこれだけを教える

### 失敗のやり直し（提案 = 少し手前に戻す）
- 通り過ぎ・猫に接近: 画面が一瞬ゆれて暗転 → 駅（猫）の 80 m 手前に戻る。レバーは「とまる」に戻る
- ゲームオーバーなし、カウントなし。相棒が一言（「もういっかい！」）

### ドア・乗客
- 駅に止まると **ドアボタン**（丸、「ドア」）が汽笛の上に出る。押すと開く → 降りる人が降り、乗る人が乗る（1 人 1.5 秒、足音）→ 終わると自動で閉まる → 相棒「しゅっぱつ しんこう！」
- ドアが開いている間はレバーを動かしても進まない（相棒「ドアが あいてるよ」）
- 乗っている人は画面上に小さな顔アイコンで並ぶ（M2・M3 の間だけ表示）。荷物も同じ列に箱アイコン
- ホームで待つ人・降りた人は 3D 側（0004）

### 相棒と吹き出し
- 相棒は運転席の右に座る 3D モデル（0003）。感情は「跳ねる／首をかしげる／ばんざい」の 3 動作だけ
- 吹き出しは DOM。画面右下の相棒の上に出る。ひらがな 1 行 20 文字まで。4 秒で消える／タップで消える
- 仮名の候補: **ピコ**（§7 で決めてほしい）

### 汽笛に反応するアクター（猫）
- 猫はふみきりの線路上で寝ている。60 m 手前に来ると相棒「ねこが ねてる！ きてきで おこそう」
- 60 m 以内で汽笛 → 猫が起きて線路の外へ歩く（2 秒）→ 通れる
- 汽笛を鳴らさずに 8 m まで近づく → 「あぶない！」急停止（速度が 0.5 秒で 0、画面が少し下に沈む）→ 猫は自分で逃げる → 失敗のやり直し
- 「反応するもの」の登録は Phase 0 の `Whistle.onWhistle` を使う。猫の距離しきい値はステージ JSON に書く

### 寸劇（カットシーン）の仕組み
- ステージ JSON に手順の列で書く。語彙は 6 つだけ: `say`（吹き出し）、`spawn`（登場）、`move`（移動）、`wait`、`cutRail`（線路に切れ目を作る）、`card`（札を出す）
- 実行中はレバーとボタンを無効にする

### ステージ JSON v1.1（追加分。v1 との互換は保つ）
| 追加 | 内容 |
|---|---|
| `stations[].stopAssist` | 自動停止の有無（既定 true） |
| `missions[].steps[]` | `{ stationId, board, alight, parcel }` の並び。最後の駅がゴール |
| `missions[].intro[]` | 開始時の相棒の台詞 |
| `missions[].onComplete` | 達成後に流す寸劇の id |
| `actors[].type` | `cat` / `passenger` / `amanojaku` を追加。`params` に距離しきい値 |
| `cutscenes` | id → 手順の列 |
| `checkpoints` | 明示しなくてよい。駅と猫の 80 m 手前を自動で使う |
